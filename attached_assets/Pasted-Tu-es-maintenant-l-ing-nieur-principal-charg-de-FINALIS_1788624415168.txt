3. AUTHENTIFICATION

Vérifie que le système d'authentification fonctionne réellement.

Il doit être possible de :

- créer un compte ;
- se connecter ;
- récupérer la session ;
- récupérer le profil ;
- modifier le profil ;
- se déconnecter ;
- conserver la session correctement ;
- protéger les pages privées.

Vérifie notamment :

GET /api/auth/session
POST /api/auth/signout
GET /api/profile
PATCH /api/profile

Évite d'avoir deux systèmes d'authentification concurrents.

Le système actuellement utilisé par l'application doit rester cohérent avec Supabase/backend.

Corrige les incohérences éventuelles entre :

- localStorage
- session backend
- Supabase Auth
- AuthProvider
- ProtectedRoute

Une page privée ne doit pas simplement considérer qu'un élément localStorage existe comme preuve suffisante d'authentification si le backend possède déjà un vrai système de session.
